# Ночной матч

Мобильный аркадный футбол 1 на 1 с видом сбоку. Синяя команда управляется игроком, красная управляется ИИ. Основная ориентация горизонтальная.

Игра: https://szjvhrkhs7-cmyk.github.io/Football/night-match/

## Запуск и проверка

Зависимостей и сборки нет. Из этой папки выполните `python -m http.server 8000`, затем откройте http://localhost:8000/. Требуется HTTP-сервер, поскольку игра использует ES modules. Для PWA требуется HTTPS либо localhost.

`node --test tests.mjs` запускает тесты на Node.js 22+. `qa.html` содержит четыре заданных горизонтальных размера, вертикальную ориентацию и синтетическую проверку нескольких указателей. Эта проверка не заменяет физический iPhone, аппаратный мультитач и измерение FPS на устройстве.

## Управление

- Телефон: удерживать стрелки слева; отдельные нажатия на прыжок и удар справа. Все четыре кнопки поддерживают независимые указатели.
- ПК: A/D или стрелки для движения, W/стрелка вверх/пробел для прыжка, J/K для удара, P/Escape для паузы.
- Матч длится 90 игровых секунд. Празднование гола, отсчёт и пауза не расходуют время.
- При потере фокуса и переходе в вертикальный режим включается пауза. После возврата нажмите «Продолжить».
- На iPhone: меню «Поделиться» в Safari, затем «На экран Домой». Ресурсы сохраняются после первого успешного открытия. Вибрация и Fullscreen API зависят от браузера; игра не требует их поддержки.

## Устройство проекта

`engine.mjs` содержит независимую от браузера физику и ИИ. Физический шаг 1/120 секунды, максимальное время одного кадра ограничено. `input.mjs` отвечает за указатели и клавиатуру, `render.mjs` за Canvas, `audio.mjs` за синтез звука. `game.mjs` связывает матч, интерфейс и жизненный цикл страницы. Стадион рисуется один раз на отдельном холсте, DPR ограничен двумя, количество частиц ограничено 160.

Файлы игры находятся только в `night-match/`. Существующая игра 5 на 5, D&D-проекты и другие репозитории не изменены. Сервис-воркер ограничен этой папкой, удаляет только свои кэши. При изменении ресурсов увеличьте CACHE в `sw.js`; обновление применяется после закрытия старых вкладок.
