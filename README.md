# ⚽ Apex Kick 2D — Modern Top-Down Soccer Simulator

Легковесный, динамичный 2D-симулятор футбола с видом сверху, написанный на чистом HTML5 Canvas и ES6+ JavaScript. Без внешних зависимостей и сборщиков — готов к запуску в любом браузере и на GitHub Pages.

![GitHub Pages](https://img.shields.io/badge/Status-Playable-emerald?style=flat-square)
![License](https://img.shields.io/badge/License-MIT-blue?style=flat-square)

## ✨ Особенности
- **Современный UI**: Glassmorphism-интерфейс, неоновые индикаторы и аккуратная анимация табло.
- **Визуальные эффекты**: полосатый газон с разметкой, динамический след за мячом, частицы при ударах и эффект тряски экрана (Screen Shake).
- **Синтезированный звук (Web Audio API)**: процедурные звуки свистка, ударов и радости трибун без скачивания MP3-файлов.
- **Игровой ИИ**: позиционная тактика союзников и соперников (прессинг мяча, пасы и игра вратаря).
- **Zero Dependencies**: весь код содержится в одном файле `index.html`.

## 🎮 Управление
| Действие | Клавиши |
|---|---|
| Движение игрока | `W` `A` `S` `D` или `Стрелки` |
| Удар / Пас | `Пробел` или `Левая кнопка мыши` |
| Прицеливание | Курсор мыши |
| Смена активного игрока | Автоматически по близости к мячу |

## 🚀 Быстрый запуск на GitHub Pages
1. Создайте новый публичный репозиторий на GitHub (например, `apex-kick-2d`).
2. Загрузите файл `index.html` и `README.md`.
3. Перейдите в **Settings** репозитория ➔ раздел **Pages**.
4. В поле **Branch** выберите ветку `main` и папку `/(root)`, затем нажмите **Save**.
5. Через 1 минуту игра станет доступна по ссылке `https://<ваш-логин>.github.io/apex-kick-2d/`.
