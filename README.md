# ⚽ Apex Kick 5v5

Браузерный футбольный симулятор 5 на 5 с видом сверху. Проект работает на чистом HTML5 Canvas и JavaScript, без внешних зависимостей и сборщика.

## Что реализовано

- матчи 5 × 5: вратарь + 4 полевых игрока у каждой команды;
- владение и ведение мяча вместо постоянных случайных отскоков;
- короткий пас с выбором подходящего партнёра;
- пас вразрез с упреждением;
- навес с отдельной фазой полёта мяча;
- удар с накоплением силы;
- ручная смена активного игрока;
- спринт и запас выносливости;
- отбор мяча и прессинг вторым игроком;
- командный ИИ: позиционная игра, давление на мяч, забегания, передачи и удары;
- ауты, угловые, удары от ворот, начальный розыгрыш после гола;
- матч длительностью 4 минуты;
- процедурные звуки через Web Audio API.

## Управление на ПК

| Действие | Клавиша |
|---|---|
| Движение | `WASD` или стрелки |
| Спринт | `Shift` |
| Короткий пас | `J` |
| Удар | удерживать и отпустить `K` |
| Пас вразрез | `L` |
| Навес | `U` |
| Отбор | `Space` |
| Смена игрока | `Q` |
| Прессинг партнёром | удерживать `E` |

Направление передач и удара зависит от направления движения/взгляда активного футболиста и использует умеренную помощь при выборе цели.

## Запуск

Откройте `index.html` в браузере или запустите простой статический сервер:

```bash
python -m http.server 8000
```

После этого откройте `http://localhost:8000`.

GitHub Pages публикует `main` из корня репозитория.
