# Пульс

Мобильный финансовый трекер для планируемых расходов. Приложение рассчитано прежде всего на iPhone и работает как статическая PWA на GitHub Pages.

## Возможности

- бюджет по месяцам;
- планируемые и оплаченные расходы;
- категории и пользовательские категории;
- аналитика по категориям и неделям;
- локальная офлайн-работа через `localStorage`;
- облачная синхронизация через Supabase Auth + Postgres + Realtime;
- экспорт и импорт резервной копии JSON;
- установка на домашний экран как PWA.

## Облако

Клиент использует только publishable key Supabase. Данные хранятся в `pulse_finance_state`, а Row Level Security разрешает чтение и запись только владельцу строки (`auth.uid() = user_id`). Секретные ключи в репозитории не используются.

## Публикация

Папка предназначена для GitHub Pages и не требует сборки. Точка входа: `pulse/index.html`.
