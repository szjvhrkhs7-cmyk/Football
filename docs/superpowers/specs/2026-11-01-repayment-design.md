# Repayment plan
User approved integration into two existing Pulse tabs, starting November 2026, with monthly entered payments and automatic balances. Loan configuration is stored in the authenticated user cloud payload, not in public source. Store a monthly total per loan (editing replaces, never adds twice); optional end-month bank balance correction. Monthly interest estimate opening balance*annualRate/12 rounded to kopecks; no claim of exact bank payoff. Historical missing months use zero actual payments, interest still accrues when a later month is recorded. Unentered future months are forecast only. Forecast snowball small1,small2,large, configured monthly budget. No automatic creation/duplication of expense entries or cash allocations. Actual reserve comes from existing savings category Подушка; keep savings manual. Local/account/cloud/export persistence and three-way merge per month. Preserve existing app data and two-tab pill navigation.
